## 1. FastAPI микросервис в виртуальном окружение

В рамках этапа создаётся FastAPI-приложение и обработчик FastApiHandler, который при запуске загружает сохранённую модель CatBoost из файла models/model.cb. API предоставляет endpoint /api/churn/, принимающий user_id и параметры объекта для выполнения предсказания.

Для запуска микросервиса необходимо перейти в директорию проекта, создать и активировать виртуальное окружение, установить зависимости и запустить приложение с помощью uvicorn.
```python
# Переход в директорию проекта
cd mle_projects/mle-project-sprint-3-v001

# Создание виртуального окружения
python3 -m venv venv

# Активация виртуального окружения Linux/macOS
source venv/bin/activate

# Для Windows:
# venv\Scripts\activate

# Обновление pip
python -m pip install --upgrade pip

# Установка зависимостей
pip install -r requirements.txt

# Запуск FastAPI-приложения
uvicorn main:app --host 0.0.0.0 --port 8000
```
После запуска API будет доступно по адресу:

http://localhost:8000

Swagger UI для проверки endpoint:

http://localhost:8000/docs

## 🚀 Процесс запуска этапа с помощью Docker

Развёртывание приложения автоматизировано с помощью Docker-контейнера. Это гарантирует неизменность среды исполнения, фиксирует версии библиотек (`scikit-learn 1.6.1`, `pandas`, `catboost`) и исключает проблемы несовместимости путей к сохранённым файлам моделей (`.pkl` и `.cbm`).

Процесс состоит из двух шагов:
1. **Сборка (Build):** Docker скачивает легковесный базовый образ `python:3.11-slim`, устанавливает изолированные системные зависимости из `requirements.txt` и упаковывает код сервиса вместе с весами моделей в директорию `/app`.
2. **Запуск (Run):** Контейнер запускает ASGI-сервер `Uvicorn`. Для связи изолированной сети контейнера с хост-машиной применяется явный проброс портов (`-p 1702:1702`).

### Команды для запуска

Выполните следующие команды в терминале из корневой директории проекта для сборки образа и старта микросервиса:

```bash
# 1. Сборка Docker-образа с тегом sprint3_8
docker build . --tag sprint3_8

# 2. Запуск контейнера с публикацией порта 1702 наружу
docker run -p 1702:1702 sprint3_8
```

## 3. Docker compose для микросервиса и системы моониторинга
## Запуск микросервиса и системы мониторинга

Для запуска FastAPI-микросервиса и системы мониторинга необходимо перейти в корневую директорию проекта, где находится файл `docker-compose.yaml`:

```bash
cd ~/mle_projects/mle-project-sprint-3-v001
```

Перед запуском необходимо убедиться, что в корне проекта находится файл `.env` со следующими переменными:

```env
PROMETHEUS_PORT=9090
GRAFANA_PORT=3000
GRAFANA_USER="admin"
GRAFANA_PASS="grafana"
APP_PORT=1702
AUTHOR=Maxim
```

Для FastAPI-микросервиса также используется файл `services/.env`:

```env
APP_PORT=1702
AUTHOR=Maxim
```

После настройки переменных окружения выполните сборку и запуск всех контейнеров:

```bash
docker compose up --build -d
```

Параметр `--build` выполняет сборку Docker-образа FastAPI-микросервиса, а `-d` запускает контейнеры в фоновом режиме.

Проверить состояние запущенных контейнеров можно командой:

```bash
docker compose ps
```

В результате должны быть запущены три сервиса:

* `main-app` — FastAPI-микросервис;
* `prometheus` — сбор и хранение метрик;
* `grafana` — визуализация метрик.

После успешного запуска сервисы доступны по следующим адресам:

```text
FastAPI:          http://localhost:1702
Swagger UI:       http://localhost:1702/docs
Prometheus:       http://localhost:9090
Grafana:          http://localhost:3000
```

Для входа в Grafana используются данные из файла `.env`:

```text
Логин:    admin
Пароль:   grafana
```

```bash

```

```bash

```

```bash
docker compose down
docker compose up --build -d
```
